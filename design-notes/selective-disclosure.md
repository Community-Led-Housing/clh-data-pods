# CLH Data Pods – Selective Disclosure Design Note

This document will explore how future versions of CLH Data Pods (v0.2+) can support:
- Field-level encryption
- Multi-key access control (coop board, auditors, researchers)
- Identity linking using `did:web`, `acct:`, and PGP-compatible schemes
- Consent and trust annotations in metadata

This follows the concept outlined in the [Cooperative Data Ecosystem Canvas](https://chatgpt.com/canvas/shared/681b53da19048191b4ccf885cfeb9093).
